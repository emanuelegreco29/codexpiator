# External Skills Map (Frontend)

Frontend work often benefits from a specialized design skill more
than from this skill's own condensed guidance. This file summarizes
the frontend-relevant rows of `shared/external-skills-registry.md` —
read that file for the full availability-check procedure and honest
notes on which install paths are actually confirmed. Don't duplicate
its table here; this is a quick pointer, not a second source of truth.

- **`frontend-design`** — reach for this when building new UI from
  scratch that needs a strong, non-generic visual point of view. Has a
  confirmed install path via the official marketplace.
- **`design-motion-principles`** — reach for this when the task is
  primarily about animation/motion/interaction quality, not just raw
  performance (see `frontend-performance.md` for the performance
  angle).
- **`impeccable`** — reach for this for a broad, general UI polish or
  critique pass across many surfaces at once.
- **`design-taste-frontend`** — reach for this for new marketing pages
  or portfolios that need to avoid a templated look.
- **`web-design-guidelines`** — reach for this for a pre-ship
  compliance audit against interface guidelines (this skill's own
  `accessibility.md` is a fast baseline, not a full audit).
- **`redesign-existing-projects`** — reach for this when upgrading an
  existing UI's design quality without breaking its functionality.

Check availability using the procedure in
`shared/external-skills-registry.md` before assuming any of these are
present — some do not have a confirmed universal install path and
availability varies by environment. If one isn't available, say so
and continue with this skill's own resource files as the fallback.
